- [x] 수정 main 반영 및 chaos test·deploy·notify 성공, EC2 healthy·배포 SHA 일치 확인.
- [ ] 팀 Discord 채널 화면에서 성공·실패 메시지 표시 확인. HTTP 전송은 성공.
- [x] 사용자 요청에 따라 main에 의도적 단위 테스트 실패 시연. test failure·deploy skipped·실패 알림, 앱 8개 ID/이미지/시작 시각/재시작 횟수·배포 기록 유지 확인. 실패 커밋 revert 후 정상 배포·알림 복구.
