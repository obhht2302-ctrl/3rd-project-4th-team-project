## 증거와 정리

- [관찰 JSON](chaos_배포차단_시연관찰_2026-10-09.json)에 Actions 결과, 안전한 테스트·배포·알림 메시지, 세 번의 서버 snapshot과 비교 결과를 보존했다. 시크릿·서버 주소·환경변수 값은 포함하지 않았다.
- 임시 실패 테스트는 revert했고 임시 점검 workflow도 제거했다. 기존 chaos workflow와 애플리케이션 코드는 시연 전 상태로 복구했다. 문서만 바뀌는 최종 정리 커밋은 배포를 유발하지 않으므로 마지막 성공 배포 SHA는 위 복구 커밋이다.
- 로컬 재검증: chaos pytest **132**, workflow 회귀 **256**, lint 진입점 회귀 **3**, 합계 **391개 통과**. Ruff 담당 범위와 actionlint 1.7.7 검사 통과. 기존 Starlette TestClient 경고 1건은 남아 있다.
- 로컬 Docker 엔진이 응답하지 않아 로컬 Docker 기반 검사 대신 체크섬을 확인한 Windows actionlint를 사용했다. chaos 이미지 빌드는 정상 main의 Linux CI와 EC2에서 실제 성공한 결과로 확인했다.
- 초기에 임시 점검 workflow의 YAML 줄바꿈을 잘못 반영한 커밋이 있었고 즉시 수정했다. 당시 chaos 배포는 발생하지 않았다. 실패 시연은 점검 workflow의 정상 검증·기준 snapshot 수집이 끝난 다음 진행했다.
- 초기 시연 준비 커밋 본문의 `KST` 표시는 Git Bash TZ 처리로 실제 UTC 출력에 잘못 붙었다. 실제 실행 시각은 GitHub ISO UTC 기록이 기준이며 이번 JSON은 KST를 명시적으로 계산했다. 복구·최종 정리 커밋의 실행일시는 UTC로 기록한다.
