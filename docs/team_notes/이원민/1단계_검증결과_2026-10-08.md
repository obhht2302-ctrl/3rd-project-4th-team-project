실제 .env와 기존 포트를 보존하려고 .venv/qa.env를 사용했다. QA 포트는 backend 18000, classifier 18010, locator 18020, verifier 18030, writer 18040, chaos 18050, mailer 18060, frontend 18501, PG 15432, Redis 16379, Mailpit SMTP 11025 / Web 18025다. 앱 서버 설정·시크릿은 사용하지 않았다.

```bash
# 루트에서 이미지 빌드·기동
 docker compose --env-file .venv/qa.env --profile local build
 docker compose --env-file .venv/qa.env --profile local up -d --no-build --wait
# 서비스별 Python 검사 예: src/chaos에서

 .venv/qa312/Scripts/ruff.exe check --isolated src
# frontend 폴더에서
 npm ci --no-audit --no-fund
 npm test
 npm run build
 npm exec --yes --package=@biomejs/biome -- biome lint src tests
# 별도 환경을 명시한 실제 장애: 원래 정상 기동한 minwon에만 수행

 COMPOSE_ENV_FILES=.venv/qa.env COMPOSE_PROFILES=local bash scripts/chaos_infra.sh postgres 6
```
