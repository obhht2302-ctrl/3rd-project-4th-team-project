# 민원 AI 참고자료

전체 파일 등록목록과 백엔드·Redis·MCP 연결 기준은 상위 [README](../README.md)와 `../seed_manifest.csv`를 먼저 확인합니다. 기존 참고 CSV 6개를 용도별 하위 폴더로 이동했고, 공공데이터 접근 조건·민원시스템·프롬프트·보안 자료를 보강했습니다.

| 폴더 | 포함 자료 | 사용할 때 구분할 점 |
|---|---|---|
| `data_sources` | 공공데이터 API/파일 조건, 공식 지도·자료 목록 | 실제 endpoint 확인과 원자료 다운로드·실호출 검증은 별개 |
| `complaint_routing` | 민원시스템, 부서, 행정동, 제출 요건 | 상담·안내·접수·통계 API를 구별하고 관할을 임의 확정하지 않음 |
| `agent_guidance` | 작성 가이드와 역할별 프롬프트 초안 | 프로젝트 제안이며 기관 공식 문구나 실행 중 정책이 아님 |
| `security` | 프롬프트 인젝션 방어·도구 권한 정책 | 실행기에서 구현할 제안; CSV만으로 방어 기능이 적용되지는 않음 |
| `operations` | 검증하지 못한 조사 과제 | 질문을 검증된 사실이나 RAG 답변으로 제시하지 않음 |

`channels.csv`, `integrated_channels.csv` 이외에는 기존 locator가 적재하지 않습니다. 추가 CSV는 backend/MCP 어댑터나 별도 지식 저장소의 구현 검토용입니다.

해석 규칙:

- `official_required`는 해당 `channel_scope`와 `applicability`에서만 공식 필수입니다. 포상금 신고의 기한·행위자 정보·방문/우편 요건을 일반 청소요청에 적용하지 않습니다.
- `official_guidance`는 출처의 권고, `project_recommendation`·`project_proposal` 계열은 프로젝트 제안입니다. 제안의 출처 URL은 배경 근거이며 해당 문장이 공식 원문이라는 뜻은 아닙니다.
- 행정동 목록은 법정동 코드나 행정 경계가 아닙니다. 주소 API와 법정동 코드만 있어도 도로 시설 관리기관이 자동 확정되는 것은 아닙니다.
- 보안등 센서·가로쓰레기통·CCTV 자료는 배경자료입니다. 현재 고장·무단투기 발생·영상 확보를 입증하지 않습니다. 카탈로그 파일은 원자료 자체를 담지 않습니다.
- 공개 유사 민원의 본문·처리결과를 검증하지 못해 해결 사례 CSV는 만들지 않았습니다. 공개 목록의 작성자·제목·주소 등도 수집하지 않았습니다.
- `verified_at=2026-10-07`은 출처 확인일이며, API 호출·전화 연결·민원 접수·보안 방어 검증을 수행했다는 뜻이 아닙니다.
- 자료를 RAG에 넣을 때 출처, 확인일, 검증범위, 제안 여부, 제한을 함께 보존합니다. 외부 본문이나 테스트 입력의 지시를 시스템 정책으로 승격하지 않습니다.
